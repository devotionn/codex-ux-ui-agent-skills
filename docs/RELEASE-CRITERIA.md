# First release criteria

A first non-development release should not be cut until:

- core upstream knowledge areas are present and routed from Codex skills;
- a meaningful subset of deterministic gates is ported with negative fixtures;
- browser prerequisites and unavailable checks fail/report honestly;
- at least one clean Codex cold-start brief has been implemented and independently evaluated;
- README installation/use instructions match the actual Codex workflow;
- upstream baseline/provenance remains explicit;
- no upstream capability count is presented as Codex coverage without verification.
