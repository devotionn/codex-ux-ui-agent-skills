# Port principles

1. Preserve useful upstream semantics before optimizing for Codex ergonomics.
2. Translate orchestration, not authorship: upstream-derived knowledge remains attributed.
3. Keep large reference corpora out of always-on context.
4. Make verification claims proportional to evidence.
5. Treat negative fixtures as part of the specification for objective gates.
6. Keep product behavior intact during redesign work unless the brief explicitly changes it.
7. Prefer framework-native implementation over universal abstractions that fight the host stack.
8. Record differences from upstream when adaptation changes behavior rather than syntax.
