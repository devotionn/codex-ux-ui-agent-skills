# Baseline facts

At adaptation start, upstream `plugin87/ux-ui-agent-skills` reports release v2.8.0 and describes:

- 19 runnable skills;
- 138 named design systems;
- 44 objective gates;
- 31 of those gates opening a real browser;
- DTCG token generation;
- WCAG 2.2 accessibility auditing;
- adapters spanning web, native, and cross-platform frameworks.

These values describe the upstream baseline only. The Codex adaptation must track its own implemented and verified coverage separately.
